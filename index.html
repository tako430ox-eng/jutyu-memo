2. 支払期日の目安

        
納品した（相手が受け取った）日から数えて60日以内、が法律上の目安です。約束の支払日がそれに収まっているか、今日から見てどうかを示します。

        

        

        

        

          この計算の前提と限界
          
    
            
  • 60日は、納品した日を1日目として数えています（例：4月1日納品なら5月30日が60日目）。公正取引委員会のQ&A（Q45）に「受領した日を算入します」とあります。4月1日の例は、この決まりに沿った私の計算です。
    • 
            
  • 「納品した日」は、相手が受け取った日です。Q&A（Q45）では、メールで送ったデータは相手のパソコンなどに記録された時点、作業やサービスは一連の作業が終わった日とされています。
    • 
            
  • 例外があります（国の資料「考え方」）。デザインなどの成果物を途中で相手に渡す場合、「一定の水準を満たしていることを確認した時点で受け取ったことにする」と合意していれば、渡した日ではなく確認した日から数えます。ただし約束の納期に相手の手元にあれば、確認が済んでいなくても納期の日から数えます。作業やサービスを毎月続けて提供する場合は、条件を満たせば月の締切日から60日（2か月）以内でよいとされています。
    • 
            
  • 受け取った成果物が最初に決めた内容に合っていないなど、受注した側に原因があって、支払いの前にやり直しをした場合は、やり直した後の成果物を受け取った日から数えます（Q&A Q46）。Q46 が扱っているのはこの場合です。発注者の都合で後から仕様が変わった場合までは書かれていません。
    • 
            
  • フリーランス法の支払期日のルールは、従業員を使っているか、役員が2人以上いる発注者から、従業員を使っていない個人（または、代表者1人だけで従業員のいない会社）が受けた仕事が対象です（第2条）。相手が1人で事業をしている場合などは対象外のことがあります。
    • 
            
  • 支払期日を取り決めなかった場合は、受け取った日が支払期日とみなされます。60日を超える日を決めた場合は、60日目が支払期日とみなされます（第4条第2項）。60日は「それまで待つ期間」ではありません。
    • 
            
  • 発注者が別の会社から受けた仕事の一部を任された「再委託」で、そのことなどが条件の通知に書かれている場合は、元の取引の支払期日から30日以内という別の決まりがあります（第4条第3項）。この計算はその場合に対応していません。
    • 
            
  • 支払日が土日などに当たり、2日以内の順延を書面などで前もって合意している場合は、60日を超えても問題としない扱いがあります（国の資料「考え方」）。
    • 
            
  • 月末締め・翌月末払いでは、月初に納品すると61日目や62日目の支払いになることがあります。Q&A（Q48）は、このような月単位の締切では60日を「2か月以内」として扱い、問題としないとしています。月末締め・翌々月末払いは、月の途中や初めに受け取った分は60日（2か月）を超えます。月末に受け取った分は、日数としては60日以内に収まることがあります。
    • 
            
  • ただし、60日を理由に、これまでより遅い支払日を新しく決めることは問題になるとされています（Q&A Q49）。
    • 
            
  • 「従業員」は、週20時間以上かつ31日以上の雇用が見込まれる人とする解説があります（弥生、弁護士監修、2025年12月更新）。
    • 
            
  • この計算は情報の整理のためのもので、法律相談の代わりにはなりません。相手がフリーランス法の対象かどうか、例外に当たるかどうかは、このページでは判断していません。
    • 
          

        

      


      

        
3. 支払いの連絡文

        
支払日の前のご案内から、遅れたときの確認まで、3段階で作れます。相手を責めず、行き違いに配慮する書き方にしています。

        

          

            
            
            
          

          

        

          

          

        

        

        

        
        

          送る前に確かめること
          
    
            
  • 請求書を送り忘れていないか、宛先や部署名は正しいか
    • 
            
  • 請求書に書いた支払期限は正しいか
    • 
            
  • 今日の時点で、もう一度入金を確かめたか
    • 
          

        

        

          

        

        

        

        

          この文面の根拠
          
    
            
  • 段階は、マネーフォワードの解説（期日前のリマインド → 期日後の再確認 → 最終確認 → それでも払われなければ法的措置を検討）に沿っています。法的措置をほのめかす文は入れていません。
    • 
            
  • 「本日〇月〇日時点で」と確認した時点を書く形、「手違いかと存じますが」「行き違いでご入金済みの場合は、何卒ご容赦くださいませ」は弥生の例文、「既にお支払いいただいている場合は…本メールはご放念ください」「万が一、前回のメールが届いていない場合は…」はマネーフォワードの例文を参考にしています。
    • 
            
  • ①は、マネーフォワードの「期日前に送る。入金予定の取引先全体に送っている案内だと分かるように」という方針に沿って書いた文で、「念のため、ご案内いたします」は例文からの引用ではありません。
    • 
            
  • ③で支払いの予定日を尋ねるのは、両社の解説にある「いつまでに入金されるかを確認する」に沿っています。
    • 
            
  • 送信後に返事がなければ、電話で確かめることも勧められています（マネーフォワード）。
    • 
          

        

      


      

        
4. それでも支払われないとき

        
公的な窓口と手続きです。どれも「何ができて、何ができないか」が違います。

        

          
フリーランス・トラブル110番

            
厚生労働省の委託で第二東京弁護士会が運営。弁護士に無料で相談でき、匿名でも構いません。電話 0120-532-110（平日9:30〜16:30）、メールや予約制のビデオ相談もあります。無料の和解あっせん（あっせん人が間に入って和解を目指す手続き）もあります。弁護士が代理人になったり、相手と直接交渉したりはしません。相談前に「時系列のまとめ」と証拠を用意するよう案内されています。
フリーランス・トラブル110番（厚生労働省）

          
行政への「申出」

            
発注者のフリーランス法違反を、公正取引委員会・中小企業庁（取引条件や支払期日など）に知らせる制度。オンラインのフォームか郵送で出します。違反を調べて是正を求めますが、話し合いの仲裁や和解はしません。申出をしたことを理由に、取引を減らす・やめるなどの不利益な扱いをすることは法律で禁じられています（第6条第3項）。
名前の扱い：行政機関には氏名と連絡先を書きます。公正取引委員会の申出書には、相手に自分の名前を伝えてよいかを選ぶ欄があり、「伝えてほしくない（匿名で調査をしてほしい）」を選べます。ただし匿名にすると、被害者の特定が必要な個別の事案は調査が難しくなると書かれています。
申出の案内（公正取引委員会）

          
支払督促（裁判所）

            
相手の住所地の簡易裁判所の書記官に申し立てます。書類の審査だけで、裁判所に出向く必要はありません。手数料は、請求額10万円までで3,200円（オンラインは3,000円）、60万円までで5,700円（同5,500円）です（相手が1人の場合）。相手が異議を出すと、通常の訴訟に移ります。相手が受け取ってから2週間以内に異議を出さなかったときも、強制執行に進むには、こちらから「仮執行宣言」を申し立てる必要があります。
支払督促（裁判所）

          
少額訴訟（裁判所）

            
60万円以下のお金の支払いを求める訴えを、原則1回の審理で解決を目指す手続きです。最初の期日までに、言い分と証拠をすべて出す必要があります。証拠は、その日にすぐ調べられるものに限られます。訴えが認められても、分割払いや支払いの猶予の判決になることがあり、話し合い（和解）で終えることもできます。判決や和解調書をもとに強制執行を申し立てられます。申し立て先は原則として相手の住所地の簡易裁判所ですが、お金の請求なら支払いをすべき場所の簡易裁判所でも起こせます。書面のほか、2026年5月21日からはオンライン（mints）でも出せます。利用は同じ裁判所に1人年10回まで。相手の申し立てや裁判所の判断で通常の訴訟に移ることがあります。判決への不服は、受け取った翌日から2週間以内の異議に限られ、控訴はできません。申立手数料は、請求額10万円までで3,500円（オンラインは2,400円）、10万円増えるごとに1,000円ずつ上がり、60万円までで8,500円（同7,400円）です（相手が1人の場合。以前は別に必要だった郵便費用を含む額）。
出典：裁判所「少額訴訟」（https://www.courts.go.jp/saiban/syurui/syurui_minzi/minzi_25_02/index.html）、裁判所「手数料額早見表」（https://www.courts.go.jp/assets/tesuuryo_hayami.pdf）（2026年11月18日閲覧）。早見表には少額訴訟だけの欄がないため、「訴えの提起（民事・行政訴訟）」の欄の額を当てています。

          
支払いが遅れたときの利息

            
フリーランス法の条文には、遅延利息の定めはありません。
民法では、お金の支払いが遅れたときの損害金は、遅れ始めた時点の法定利率で計算し、契約で決めた利率がそれより高ければその利率によるとされています（第419条）。法定利率は今（2026年4月〜2029年3月）は年3%です（法務省）。
取適法（旧下請法）には、対象の取引で支払期日までに払われなかったとき、受け取った日から60日を過ぎた日から実際に払う日まで、未払いの額に公正取引委員会規則で定める率（年14.6%）の遅延利息を払う決まりがあります（第6条）。取適法の対象になるかは、発注者と受注者の規模や委託の内容で決まり、このページでは判定していません。両方の法律に違反する場合は原則としてフリーランス法を優先し、取適法の勧告は重ねない、とされています（公正取引委員会、2026年1月1日改正）。これは行政の勧告についての決まりで、遅延利息には触れていません。
連絡文には、利息の話を自動では入れていません。

        

        

        

        

          確かめられなかったこと
          
    
            
  • 両方の法律が当てはまる取引で、取適法の遅延利息の決まりがどう扱われるかは、両法の関係を書いた公正取引委員会の資料（2026年1月1日改正）にも書かれていませんでした。対象になりそうなときは、110番などで相談してください。
    • 
            
  • 民法の損害金を実際に請求するときの手順や、何日分から数えるかは、このページでは扱っていません。必要なときは110番などで相談してください。
    • 
            
  • 申出のオンラインフォームに、名前を相手に伝えるかを選ぶ設問があるかは、入力要領を最後まで読めず確かめられていません。
    • 
            
  • 名前を伏せても、申出の内容から相手に誰のことか推し量られないよう配慮する、という記述は、読んだ案内には見当たりませんでした。
    • 
            
  • 支払督促の裁判所のページには「手数料は訴訟の半額」とありましたが、郵便費用を含めた今の早見表の額では半分になりません。このページでは早見表の額を載せています。
