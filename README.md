# 受注メモ（ベータ版）

フリーランスで仕事を受けるときに、条件の確認文と、支払期日（納品から60日）の目安を作る無料のウェブページです。案件の記録、支払いが遅れたときの連絡文、相談窓口の案内もあります。

- 公開先：GitHub Pages（`index.html` 1枚。外部のライブラリやフォントは使いません）
- 入力した内容は、使う人の端末のブラウザ（localStorage）にだけ保存し、どこにも送信しません
- アクセス解析や広告は入れていません
- 法律や窓口の説明は公的な資料で確かめたもので、確認日をページに書いています。弁護士などの専門家の判断ではありません

## 設定

`index.html` の `CONFIG` で、版、更新日、情報の確認日、運営者名、感想フォームのリンク（`formUrl`。空なら案内を出さない）を設定します。
